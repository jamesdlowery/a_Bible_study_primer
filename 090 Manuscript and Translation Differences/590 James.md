# James: Textual and Translation Differences

**Translations covered:** AMP, CSB, ESV, KJV, NKJV, NASB, LSB, NIV, NLT, RSV2CE, ASV, WEB, DR, CPDV, Darby, YLT, SLT, WBT, AKJV, NRSV-CE, RSV, NABRE, ERV, NET, BSB, TRB, CJB

A systematic search did not find a confirmed case in James where the tracked translations render a verse with different, meaning-changing wording. That reflects a gap in how thoroughly this book has been searched, not a settled finding that no such case exists.
